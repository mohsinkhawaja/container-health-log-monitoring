# Defect report

- **Summary**: Observable symptom and affected service
- **Environment**: Commit, image tag, Python/Docker versions, Compose project, OS
- **Impact and severity**: Who is affected and which operation is blocked
- **Preconditions**: Relevant fixtures, log sample window, configuration
- **Steps to reproduce**: Commands or numbered steps with synthetic inputs
- **Expected result**: Required status, body, state or log behavior
- **Actual result**: Observed status, exit code or failed assertion
- **Evidence**: JUnit case name, sanitized JSON summary and relevant log excerpt
- **Reproducibility**: Runs affected, first failing commit or known-good comparison
- **Resolution verification**: Fix commit, rerun link and regression coverage

Label controlled failures as test fixtures. Keep access tokens, personal data and raw production logs out of public reports.
